One act or several — the four cases

Two intents the game resolved correctly as a single act, the compound one it should have flagged and didn't, and one with TWO acts and zero physical changes. Write a question, run all four, see which pass. Use {{INTENT}} where the intent goes.

Judged automatically: a bare number means several when > 1; otherwise the words several / multiple / one / single are read from the answer. Anything it can't read is marked unreadable and counts as a fail — a question whose answer you can't parse is not a question the referee could use. The ✓/✗ on each case overrides the judge. Tries defaults to 3 on purpose: temperature 0 is not reproducible across sessions here — the same prompt on the same intent gave opposite answers an hour apart (llama.cpp's prefix cache), while being 6/6 stable within a session. A one-shot result is not evidence. The verdict is the majority across tries.
