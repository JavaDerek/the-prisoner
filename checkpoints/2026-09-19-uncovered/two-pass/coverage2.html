Coverage in two passes

The idea: pass 1 only describes the intent — no list of kinds anywhere in its prompt — as three fields: what it acts on, what the world looks like afterward, and the stated aim if there is one. Pass 2 gets that description and does the mapping: is the stated aim a kind; what is the nearest kind to the physical result and does it fit; a fit percentage for it, then covered or uncovered. The mapping stays with the model; the threshold box is only a second way to read the same percentages, and the score line says which one it used. The extra columns show each pass's output so a ✗ can be blamed on the description or on the mapping.

Pass 1 — describe · {{INTENT}} is replaced by the intent

Pass 2 — map · {{EXTRACTION}} is pass 1's JSON; {{INTENT}} is the intent, or removed when the toggle is off

Both passes: temperature 0, one user message, a strict JSON schema on the reply so the fields always parse.
